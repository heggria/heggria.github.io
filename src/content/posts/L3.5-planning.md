> L 是 Life 的缩写。从毕业后的第一个国庆（2021 年 10 月）开始，我每半年回顾一次工作和生活，再写下一个周期的计划。这篇记录的是 2024 年 10 月的想法。

# L3 回顾（2024.4.1-2024.10.1）

L3 是到目前为止，我过得最稳定、也最快乐的半年。工作有了几个落地的项目，生活和感情也有了变化。

## 事业

公司前端团队有百人左右。这半年，我对自己在技术学习、业务建模、工程化和代码架构上的能力更有信心。具体做了这些事：

- 从零到一落地了一套较为完善的 Monorepo 方案，解决了我们团队的代码复用问题，提高了代码的可维护性。
- 对于函数式编程，函数组合有了更加深入的理解，并在本业务团队中推广了 VueUsePro，一个本人维护的组合式函数库，用来整理组内的组合式逻辑。
- 设计并落地了基于 Lexical 的富文本编辑框架 Lext，并在组内推广使用。
- 维护了一套组件库 Nexus，将各种业务组件进行了抽象，提高了代码的复用性。
- 打造了一套轻量配置化的表单框架 Fee，用于减少 B 端表单的重复开发。
- 编写了几个提效的 Vite 插件，解决了开发过程中遇到的一些痛点。

业务开发中的 bug 数量在下降。L3 期间，每月平均有效 bug 是 5 个；UI 还原度也基本没有收到投诉。这让我对自己写的代码更有信心。

同事相处方面，我和本组（职测）、另外一组（校招）以及 +1 的合作都比较顺利。除了自己交付，也希望能帮组里解决一些共同的问题。

开源方面也开始有了一些记录：

- Lext 已经开源
- VueUsePro 已经开源
- 向 vue/core & eslint-plugin-vue 提交了几个 PR
- 向 vite、vitepress-sidebar、vueuse 提交了几个 issue

这半年也有了自己的博客，可以把项目和笔记放在一个地方。

- 博客基于 antfu 二次开发，使用 VitePress + unocss + primevue
- 博客已经接入评论系统，在线人数，google analytics
- 使用 github action 自动打包并生成 docker 镜像上传到制品库，自动部署到服务器
- 自动续签 https 证书
- 写了一个我自认为非常好用的工具 - 薪资计算器

目前月访问人数 200 左右，还得继续推广～

## 生活

生活里最大的变化是通勤、养猫和运动。

四月份我卖了 F90m，买了一辆小牛 nxt 大师，并进行了一定程度的魔改，当时最高速度达到过 86km/h，每天骑着它上下班，通勤时间相比坐地铁减少了一半（差不多每天节约了 50 分钟，一周就是 4 个小时）。关键在于，平常周末出行再也不用打车了（你知道的，北京的打车有多贵），五一我和我室友直接去了延庆音乐节，还去了通州音乐节，出行比以前自由了。目前我的行驶总里程已经来到了 6000km，app 上面显示省了 3000 块钱 + 18个小时，骑车已经成了日常的一部分🏍。

还有奶糖。之前我和室友养过奶油（柯基）、奶酪（泰迪），但两个人都做程序员，没时间遛狗，后来都送走了。今年一月，我们去北京一家猫舍，花 12800 元买了一只淡化色蓝金渐层，取名奶糖。现在他已经 1 岁，每天回家会在门口等我，喜欢让我帮他撸毛、揉肚皮。我现在算是猫奴了🐱。

最后是开始运动了。以前基本不运动，最近觉得体力和精力不如以前，于是开始每周跑四次，每次半小时，希望接下来能坚持💪。

## 感情

在 L2 之前，我没想过会遇到现在的女朋友。中间发生了很多事，我们在今年 6 月 28 日正式在一起。两个人都是前端程序员，有共同话题，技术上也能互相帮助。

认识她之前，我喜欢宅着，也会靠二次元逃避一些现实里的不如意。现在越来越喜欢生活了。她在身边，很多事情也可以一起想办法改变。我希望能和她把往后的日子过好🩷。

# L3.5 规划（2024.10.1-2025.4.1）

这半年的计划，是在生活稳定下来的基础上，继续补技术和生活技能。

## 事业

技术学习想集中在这些方向：

- 算法（leetcode），在本周期结束时，能够熟练掌握常见数据结构与算法，并能够独立解决中高难度的算法题，举一反三
- 编译原理（JS 层面），包括 TS、打包工具、ESLint 等，能够熟练掌握编译原理，能够独立开发一套编译、构建工具
- V8 原理，包括 JIT、GC、内存管理等
- VSCode 及其相关插件开发，对于 VSCode 整体的架构有足够深入的了解，能够独立开发 VSCode 插件

工作方面：

- 保持每月有效 bug 量在 5 个/月以下
- 利用 Monorepo 的分包，结合模块联邦+vue-route，打造一套性能优秀，模块部署解耦的微前端方案
- 制作 CLI 工具，完善 Monorepo 的开发流程

开源方面：

- 及时同步更新博客，日更
- 完善 Lext，支持更多的富文本编辑功能
- 完善 VueUsePro，支持更多的组合式函数
- 对各个开源库的理解更加深入，并提出更多的 issue 和 PR

## 生活

- 坚持每天跑步，每周四次，每次半小时
- 拿到驾照，并掌握开车技能
- 提升其他生活技能，如烹饪、理财等

## 感情

- 互相支持，互相鼓励，互相成长
- 沟通，沟通，再沟通
- 任何事情，先低头再说，避免矛盾扩大
- 大事化小，小事化了

周期结束后考虑跳槽，目标是一线大厂。
