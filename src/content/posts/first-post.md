---
title: 我理解的前端几个层次
date: 2024-03-18T16:00:00.000+00:00
---

我暂时把前端开发分成下面几个层次。它们更像是学习方向的划分，不是严格的架构分层。

- 表现层：程序展现给用户的样子，重点在样式调整和实现细节的熟练度
- 抽象层：把编程思想用于代码组织，结合框架设计便于维护的代码
- 框架层：理解框架原理和 API 约束，知道这些 API 为什么这样设计，以及如何选择框架
- 编译层：理解前端语言和框架如何转换为 JavaScript，需要补 JavaScript 原理、编译原理和算法
- 运行层：理解 JavaScript 如何在机器上执行。学习对象包括 JSC、V8、Node、Bun，也会涉及汇编和操作系统等知识
